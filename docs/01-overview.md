# معرفی پروژه هلی‌بار

## هلی‌بار چیست؟

**هلی‌بار** یک پلتفرم تحت وب برای مدیریت عملیات حمل‌ونقل بار شهری است. کار اصلی آن **صدور بارنامه شهری** از طریق وب‌سرویس رسمی **سپاد (UTCMS)** شهرداری است، به‌همراه مدیریت ناوگان، احراز هویت دوعاملی رانندگان و استعلام سهمیه سوخت.

| مورد | مقدار |
|------|-------|
| نام رسمی | هلی‌بار — سامانه مدیریت بارنامه و ناوگان |
| کد شرکت پیش‌فرض | `24981` |
| نسخه API | `2.4.0` |
| پورت پیش‌فرض | `3000` |
| زبان رابط کاربری | فارسی (RTL) |
| تقویم | جلالی (شمسی) |

## مسئله‌ای که حل می‌کند

صدور بارنامه شهری در ایران فرآیندی چندلایه است: استعلام ناوگان، استعلام راننده، دریافت کد دوعاملی پیامکی، محاسبه هش امنیتی و ثبت نهایی در وب‌سرویس SOAP شهرداری. انجام دستی این مراحل برای هر پلاک، هم کند است و هم خطاپذیر.

هلی‌بار این زنجیره را خودکار می‌کند:

- استعلام گروهی پلاک‌ها و رانندگان از سپاد
- دریافت و تطبیق خودکار کد OTP از پیامک
- ثبت بارنامه به‌صورت تکی، دسته‌ای (Batch) یا خودکار در بازه‌های زمانی
- محاسبه سهمیه سوخت بر پایه تعداد باربرگ در دوره‌های ۱۵ روزه جلالی

## قابلیت‌های اصلی

### ۱. صدور بارنامه
- فرم صدور تکی با اعتبارسنجی کامل طرفین، محموله و بار مالی
- صدور دسته‌ای از فایل اکسل با کنترل هم‌زمانی (Concurrency) و ایزولاسیون خطا
- صدور خودکار (Auto-Register) در بازه‌های زمانی مشخص برای هر پلاک
- حالت رفت‌وبرگشت (Round Trip) با ایجاد جفت بارنامه
- کلید Idempotency برای جلوگیری از ثبت تکراری

### ۲. مدیریت ناوگان
- ثبت پلاک با ساختار دقیق پلاک ایران (۴ بخش + نوع)
- وضعیت مجوز: معاینه فنی، بیمه، کارت هوشمند، سهمیه
- سوئیچ فعال/غیرفعال برای هر پلاک
- تفکیک مالکیت چندمستأجری (هر پشتیبان فقط پلاک‌های خودش را می‌بیند)

### ۳. احراز هویت دوعاملی (OTP)
- درخواست کد برای راننده توسط پشتیبان
- دریافت خودکار کد از پنل پیامک از طریق Webhook
- استخراج کد ۴ تا ۶ رقمی از متن پیامک
- شمارش معکوس انقضا و صف اقدامات در انتظار

### ۴. استعلام سوخت
- محاسبه سهمیه بر پایه تعداد باربرگ، تناژ و مسافت
- تفکیک دوره‌های ۱۵ روزه جلالی (مرحله اول: ۸ تا ۲۳، مرحله دوم: ۲۳ تا ۸ ماه بعد)
- تاریخچه دوره‌ها و وضعیت واریز

### ۵. مدیریت کاربران و اشتراک
- نقش‌های ADMIN / SUPPORT / DRIVER با دسترسی متفاوت
- چرخه اشتراک ۳۰ روزه با هدرهای هشدار
- مسدودسازی خودکار در صورت انقضای اشتراک
- پنل ادمین برای ساخت، ویرایش ظرفیت، مسدودسازی و حذف کاربر

### ۶. گزارش و آرشیو
- داشبورد عملیاتی با آمار زنده
- آرشیو بارنامه‌ها با جستجو و فیلتر
- گزارش خطاها با کد خطا و راهنمای اقدام
- خروجی PDF بارنامه و خروجی اکسل

## اصطلاحات دامنه

| اصطلاح | معنا |
|--------|------|
| **بارنامه / باربرگ** | سند رسمی حمل کالا (Bill of Lading / BOL) |
| **سپاد / UTCMS** | سامانه یکپارچه حمل‌ونقل بار شهری شهرداری |
| **صادرکننده (Issuer)** | شرکت حمل‌ونقل دارای مجوز که بارنامه صادر می‌کند |
| **پشتیبان (Support)** | اپراتور شرکت که ناوگان و رانندگان را مدیریت می‌کند |
| **راننده (Driver)** | دارنده خودرو که کد دوعاملی را تأیید می‌کند |
| **پلاک کددار** | پلاک نیازمند ثبت دستی/OTP در سامانه شهرداری |
| **TraceCode** | کد رهگیری بازگشتی از سپاد پس از ثبت موفق |
| **Salt** | عدد تصادفی در فرمول هش امنیتی سپاد |
| **ظرفیت پلاک** | سقف تعداد پلاک مجاز هر پشتیبان (۵۰/۱۵۰/۳۵۰/۵۵۰/۷۰۰) |

## نقش‌ها در یک نگاه

```
ADMIN (heliya)
  └── دسترسی کامل: ساخت کاربر، تنظیمات، همه‌ی پلاک‌ها، تأیید پرداخت
       │
       ├── SUPPORT (پشتیبان/صادرکننده)
       │     └── فقط پلاک‌ها و رانندگان تخصیص‌یافته به خودش
       │          └── DRIVER (راننده)
       │                └── فقط ورود کد دوعاملی
```

## وضعیت فعلی توسعه

| بخش | وضعیت |
|-----|-------|
| فرانت‌اند React | کامل و فعال |
| سرور Express | کامل و فعال (ذخیره‌سازی JSON) |
| بک‌اند FastAPI | پیاده‌سازی‌شده، جدا از Express |
| اتصال سپاد | حالت `live` و `simulation` هر دو موجود |
| ماژول اندروید | مدل و شبکه پیاده‌سازی‌شده |
| پایگاه داده | JSON در Express، SQLAlchemy در FastAPI |

> **هشدار امنیتی**: در نسخه فعلی رمز عبور کاربران در `data/system_users.json` به‌صورت **متن ساده** ذخیره می‌شود و توکن‌ها JWT واقعی نیستند (`jwt_token_<id>_<timestamp>`). پیش از انتشار عمومی باید به هش bcrypt و JWT امضاشده مهاجرت شود. جزئیات در `04-authentication-rbac.md`.
